# tictactoe_app
The game ( index.html ) — a polished, mobile-first PWA with:   2-player mode (pass and play)   Vs Computer mode with 3 difficulties — Easy (random moves), Medium, and Hard (unbeatable minimax AI)   Score tracking for X, O, and draws   Animated wins, dark modern UI, app icons included   Works offline once installed as an app  easy to play with kids.
